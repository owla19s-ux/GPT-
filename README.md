# GPT- 写作实验室

这是一个用于长期积累写作样本、风格研究、人物与世界观资料，并逐步形成个人写作方法论的实验仓库。

## 当前阶段

v0.1：烟雨江南作品写作特征研究。

参考材料：
- 《尘缘》：用户提供的 EPUB
- 《狩魔手记》：用户提供的 TXT

> 本仓库不保存受版权保护作品的完整转载文本。作品分析以用户提供的材料为研究依据，沉淀为抽象的写作方法、结构观察和原创规则。

## 目录

- `01_写作样本/`：用户自己的样本、合法可再分发的参考材料
- `02_作者研究/`：作者与作品的写作特征分析
- `03_写作规则/`：从样本中提炼的可执行写作规则
- `04_角色/`：角色人格、关系与长期状态
- `05_世界观/`：世界设定与运行规则
- `06_作品/`：原创正文、草稿与修订稿
- `07_素材/`：剧情、场景、对白、灵感

## 核心目标

不是机械模仿某位作者，而是研究优秀作品的结构机制，再与用户自己的表达、人物和世界观结合，形成独立的长期写作系统。
