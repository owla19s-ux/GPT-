# GPT-写作实验室

这是一个用于长期积累写作样本、作品资料、写作方法、作者研究与创作实验的个人写作实验室。

核心目标不是机械模仿某位作者，而是从实际创作和研究中提炼结构机制、叙事方法、节奏控制、人物塑造、读者体验等可复用经验，并逐步形成属于自己的长期写作系统。

## 总体结构

```text
00_系统/       公共写作系统、方法论、节奏与温度、结构、角色、世界观、读者体验
01_作品/       每部原创作品的独立封闭空间
02_作者/       作者自身的写作规律、习惯与长期研究
03_资料/       不属于具体作品的参考资料、灵感、素材与研究材料
04_实验/       尚在验证中的写作、AI、结构等实验
05_归档/       已完成或暂停但需要长期保留的资料
```

## 核心原则

### 1. 作品内部封闭

一部作品的正文、设定、角色、世界观、创作过程、专属素材和旧版本尽量全部留在自己的作品目录里。

例如：

`01_作品/01_试验/`

未来新增小说只需要增加新的作品目录，不需要重构整个仓库。

### 2. 公共系统只保存可复用经验

作品中发现的方法先留在作品自己的创作脉络中。经过验证、提炼后，才进入 `00_系统/`。

例如：

> 《试验》第一章某段节奏太慢。

属于作品经验。

进一步提炼为：

> 高信息密度阶段应通过动作、情绪、环境或留白稀释解释压力。

才属于公共写作方法。

### 3. 经验 → 实验 → 方法

作品负责产生经验，实验负责验证经验，系统负责保存经过提炼的经验。

### 4. 不确定内容不能伪装成确定事实

特别是世界观和长篇创作，需要区分：世界事实、角色认知、读者认知、作者真相、未决设定。

### 5. 修改核心设定要追踪影响

长篇设定是网络结构。修改一个核心节点时，要检查它对角色、章节、世界观、读者认知和后续剧情的影响。

## 资料原则

仓库未来可以保存与写作相关的其他资料，但不要求所有资料都属于小说。无法立即归类的内容进入 `03_资料/` 或 `04_实验/`，后续再整理。

对于受版权保护的参考作品，不保存不必要的完整转载文本；研究结果以抽象分析、结构观察和原创规则为主。

## 长期目标

让这个仓库逐渐从“存小说的地方”变成一个真正能够持续学习、验证、沉淀和迭代的个人写作操作系统。


## 《试验》资料仓 v0.2

《试验》的资料组织正在从传统的“人物/世界/故事”分类，调整为以**时间为核心锚点**的世界运行结构。

当前确定的核心关系：
- 世界：定义世界本身，当前区分“异世界”和“蓝星往事”。
- 人物：主要角色、概念体保持独立资料；普通角色可随主要故事线管理，但人物本身可以跨故事线持续存在。
- 故事线：作者选择的观察/叙事路径；故事线结束不等于其中人物或世界运行结束。
- 事件：独立发生节点，可以同时关联人物、故事线、区域、概念体、组织等对象。
- 时间线：所有对象共同运行的总时间坐标，采用横向时间轴与纵向轨道。
- 王度视角：世界运行的有限观察窗口，正文只呈现王度能够接触到的部分。

当前资料仓结构以 `01_作品/01_试验/资料仓结构_v0.2.md` 为准；多维时间轴设计见 `01_作品/01_试验/05_时间线/时间线多维表格设计.md`。
