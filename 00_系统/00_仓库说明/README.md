# 仓库说明

GPT-写作实验室采用「公共系统 + 独立作品 + 作者研究 + 资料 + 实验 + 归档」结构。

## 核心原则

1. 作品内部保存该作品自己的正文、设定、角色、世界观、创作过程、版本与废稿。
2. 公共系统只保存经过提炼、可以跨作品复用的方法、模型、规则与经验。
3. 一个经验先在作品中产生，再进入实验验证；确认具有普适性后，再进入公共系统。
4. 不把单一作品的设定污染公共系统。
5. 暂时无法归类的资料进入 `03_资料/99_待整理/`，以后再整理。
6. 已完成、暂时不活跃但仍需保留的内容进入 `05_归档/`。

## 信息流

作品实践 → 创作记录 → 实验验证 → 方法提炼 → 公共系统 → 新作品复用 → 再验证
