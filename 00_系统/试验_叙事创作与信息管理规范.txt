《试验》叙事创作与信息管理规范
版本：v0.1
用途：作为《试验》长期创作、章节规划、世界构建与正文检查的工作规范。

一、核心创作原则

1. 世界持续运行，但镜头有限跟随。
世界中没有被镜头展示的事情仍然可以发生。正文不为了证明“世界是活的”而频繁切换地点和视角。

2. 局部清楚，整体模糊。
让读者清楚当前场景、人物正在做什么以及眼前发生了什么；对于更大的世界结构、人物身份和事件机制，可以通过长期积累逐渐建立。

3. 不直接给答案，给足够让读者形成答案的东西。
优先使用动作、物品、环境、对话、人物反应、痕迹和结果释放信息，让读者自己连接。

4. 不为了“像小说”而增加文字。
新增文字必须承担信息、画面、人物、情绪、节奏或伏笔作用。没有作用的解释、重复描写和模板化修辞应删除。

5. 先推进剧情，再抠细节。
先确定人物下一步为什么行动、去哪里、遇到什么；确定骨架后，再逐句打磨动作、环境、对话和微小反应。

二、世界构建

世界设定不是百科全书，而是让作者能够判断“这个世界为什么能发生这些事情”。

逐步建立：
- 世界底层规律
- 概念体与觉醒
- 地理与区域
- 国家、组织、聚落和社会结构
- 交通、资源、信息传播
- 世界历史
- 当前世界状态
- 重要人物与势力的长期轨迹

世界允许存在大量作者知道、但正文暂时不展示的信息。

三、章节推进

每章开始前先检查上一章结束状态：
- 人物位置
- 身体状态
- 情绪状态
- 人物关系
- 外部威胁
- 已解决问题
- 未解决问题
- 王度知道什么
- 其他角色知道什么
- 读者知道什么

然后确定本章：
- 剧情目标
- 人物目标
- 世界信息目标
- 情绪/温度
- 本章需要新增的问题
- 本章需要回答的问题
- 镜头范围
- 需要释放的小信息

剧情必须从上一章状态自然继承，而不是凭空跳跃。

四、信息分层与权限

每条重要信息都区分：
- 作者事实：作者当前确定的世界事实
- 角色认知：各角色知道或不知道的内容
- 读者认知：正文目前已经让读者知道的内容
- 镜头内容：本次叙事实际展示出来的内容
- 未决设定：尚未决定或故意暂不确定的内容

信息状态可以记录为：
隐藏 → 暗示 → 局部透露 → 明确 → 确认 → 揭示。

作者知道的内容不等于读者知道；读者知道的内容也不等于王度知道。

五、世界信息的“小颗粒”机制

通过小信息长期积累建立大结构：
- 一个物品
- 一个徽记
- 一个地名
- 一句对话
- 一个动作
- 一个数字
- 一个异常现象
- 一个人物反应
- 一个事件留下的痕迹

例如“废弃地下传送阵”可以通过阿英一句“一个组织”透露出组织、交通体系和世界结构，而无需专门解释世界观。

六、视角与镜头

检查：
- 当前场景由谁观察？
- 这个人能看到、听到、理解什么？
- 是否无意进入其他角色的内心？
- 是否把作者知道的信息错误地塞给角色或读者？
- 是否存在无必要的视角切换？

允许独立的作者叙事窗口，例如楔子可以展示王度尚不知道的事件。

七、角色塑造

角色不是固定属性表，而是在世界中持续运行的人。

重点记录：
- 相对稳定的人格与长期倾向
- 行为指纹
- 说话方式
- 情绪触发
- 对不同人物的不同反应
- 身体与生活痕迹
- 能力表现
- 关系变化
- 重要经历与阶段性轨迹

不要求每章更新完整角色档案。重要变化发生时记录轨迹即可。

角色应通过行为逐渐被认识，而不是一次性介绍身份、性格、能力和背景。

检查标准：
如果删除角色名字，只看他的动作、语言和反应，仍能大致认出这个人，则人物辨识度较强。

八、角色与世界的持续运作

角色离开镜头后不等于停止存在。
世界中的人物可以继续行动、改变关系、经历事件，只是正文暂时没有展示。

新角色不应为了“介绍角色”而出场。出场应至少承担推动事件、提供信息、制造冲突、改变关系、展现世界、留下悬念或形成对比等作用。

九、章节温度与阅读节奏

章节温度包括紧张、压迫、平静、温暖、疲惫、疑惑、悲伤、荒诞、兴奋、空旷等阅读感受。

检查：
- 是否长时间维持同一种强度？
- 高强度场景之间是否有自然缓冲？
- 缓冲是否仍然推动人物或世界？
- 是否为了制造气氛而过度堆砌环境？
- 对话、动作、环境和留白的比例是否自然？

十、微细节调整

优先检查：
- 一个动作能否替代一句解释？
- 一个物品能否承担人物或世界信息？
- 人物反应是否符合其当前状态？
- 对话是否像这个人会说的话？
- 细节是否在重复已经建立的信息？
- 细节是否改变了读者对人物或世界的认识？
- 是否存在不必要的形容词、心理解释或作者总结？

原则：重复出现可以，但再次出现最好产生新的意义。

十一、章节完成后的读者检查

脱离作者设定，只按正文模拟第一次阅读：
- 我现在知道什么？
- 我不知道什么？
- 我正在猜什么？
- 我是否迷路？
- 我是否感到信息不足？
- 我是否感到信息过量？
- 哪里需要自己构建画面？
- 哪里构建负担过高？
- 哪个细节让我记住了人物？
- 哪些解释可以删除？
- 本章结束后，我产生了什么新问题？

区分“暂时不知道”和“根本没看懂”。

十二、长期信息考古

重要信息不仅记录“是什么”，还应尽量记录：
- 首次出现位置
- 当时的读者理解
- 当时的角色认知
- 后续确认/反转位置
- 与哪些人物、事件、物品有关
- 当前解释是否已经改变

目标不是让读者无法理解，而是让旧信息在后续获得新的意义。

十三、最终工作流

世界设定
→ 当前世界状态
→ 上一章状态继承
→ 本章剧情目标
→ 人物自然行动
→ 信息权限
→ 信息释放计划
→ 镜头范围
→ 场景/对话设计
→ 正文
→ 角色视角检查
→ 读者视角检查
→ 信息密度检查
→ 阅读疲劳检查
→ 章节温度/节奏检查
→ 微细节打磨
→ 正式版本
→ 重要变化进入轨迹记录

核心总结：
让世界自己说话，让读者自己连接，让角色自己活着。
