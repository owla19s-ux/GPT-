## 一、核心叙事方式

《试验》不是“王度完成一个任务，再进入下一个任务”，而是：

**世界持续运行 → 各条故事线自行发展 → 事件产生长期因果 → 王度在某个时间点进入其中 → 正文截取王度能够观察到的窗口。**

- 故事线可以在王度看不见的时候继续运行。
- 一条故事线可以跨越多个章节。
- 多条故事线可以在同一事件或章节中交叉。
- 故事线结束不代表人物、世界、组织或事件停止运行。
- 时间线记录“什么时候发生”，故事线记录“因果/观察路径”。
- 王度不是世界运行的中心，而是正文的主要观察窗口。

## 三、核心线补充

### 1. 王度主线
蓝星27年 → 推门 → 穿越 → 第一章生存 → 与阿英同行 → 小镇生活 → 学习与劳动 → 建立社会关系 → 身份与通信 → 接触更大的世界 → 概念体 → 可能性 → 回地球。

核心变化不是力量成长，而是：

> **从观察世界的人，逐渐变成参与并改变世界的人。**

### 2. 蓝星往事线
已经单独整理到 `03_角色/王度_蓝星往事.md`。本线主要服务人物，不应重新拆成大量零散人物线。

### 3. 门先生 / 门线
- 门先生没有死亡。
- 门先生与“门”存在深度合作。
- 存在“门用他”的状态。
- 第一章巨大光团只是现象与尺度参考，不据此写死能力上限。
- 后期方向是门先生结束自己作为“门”的承载者/拥有者状态，并将“门”的概念与权柄归还世界。

### 4. 度瓜线
王度带入西瓜 → 阿英获得种子 → 当地培育 → 传播 → 出现“度瓜” → 王度后来在市场重新看到它。

这条线的意义是：王度做过的一个小动作，可以在他离开之后继续运行很多年。

### 5. 啤酒 / 微生物 / 金属罐线
王度不知道自己携带了地球微生物；制作啤酒后，新的生物结构进入当地世界。

随后可以形成：

**啤酒 → 发酵/食品变化 → 啤酒罐 → 阿英交给铁匠 → 工艺变化 → 后续社会影响。**

重点不是“王度主动科技输出”，而是世界接住了一个普通行为。

### 6. 身份凭证 / 网络线
身份凭证不是普通手机，也不是普通身份证，而是生物、概念、身份系统、信息网络和公共服务的结合。

王度获得身份凭证后，会自然想到手机、相机、相册、音乐、论坛等概念，但“知道概念”不等于“知道实现方法”。

信息传播方向暂定为：

**店老板 → 同行业者 → 相关职业/组织 → 研究者 → 概念体。**

### 7. 学徒 / 小镇生活线
王度 → 阿英 → 周律 → 老张 → 实际劳动。

它不是升级教学，而是让王度开始真正理解这个世界的人怎样生活。

小镇生活网络还包括面馆、铁匠、另一家猪肉铺、度瓜培育者、邮差等。

### 8. 看不见 / 不存在线
核心问题是：

> “是他们不存在，还是你看不见？”

先让读者感到异常，再逐步发现原因，不提前把最终解释写死。

“王度过去假装看不见”与“后来真的看不见”的联系目前只标记为【关联候选】。

### 9. 概念体 / 可能性线
概念体可以拥有意识、意志、偏好和选择；人与概念体可以合作、契约、交易、友谊、寄生等。

可能性是王度深层主线的重要候选，但以下仍未确认：是否为独立概念体、是否参与穿越、是否主动选择王度、是否与门合作。

## 五、状态规则

- **【已确认】**：当前版本稳定保留的内容。
- **【部分恢复】**：历史资料已有内容，但因果链尚不完整。
- **【关联候选】**：存在关系，但不能当作作者已确认意图。
- **【核心未决】**：重要方向存在，关键机制尚未确定。
- **【历史提出】**：旧资料曾提出，不自动视为当前设定。
- **【已废弃】**：已被后续版本明确替代。
