# 《试验》故事线与世界运行总纲（当前版）

> 状态：创作中 / 当前有效设定汇总
> 用途：作为故事线池、时间线支点、情节落点与王度“取景”写法的总纲。
> 原则：不把尚未确定的解释写死；故事线可以继续增加、拆分、交叉。

## 一、核心叙事方式：故事线先运行，王度负责取景

《试验》不是传统“英雄史诗式”的全知视角故事。

核心方法：先建立一条条会自行运行的故事线，再把这些线放到合适的时间节点；正文只截取王度能够看到的某个窗口。

世界不是围绕王度暂停运行。王度看见一个节点之前，这条线已经可能运行了很久；王度离开以后，这条线仍然继续。

- 世界设定可以持续补充；
- 线性故事可以随时增加；
- 不需要现在就决定所有章节；
- 最终根据时间线、因果关系和人物状态，把某个节点“取景”出来；
- 宏大的世界变化多数通过王度日常生活中的细节体现；
- 只有少数必须展示宏观事件的情节才切换视角。

核心感觉：一个可能有几百万吨内容的世界，王度最终只看见其中约1GB的窗口。

## 二、故事整体结构

表层故事：王度从地球进入另一个世界，并在那里生活。

中层故事：王度不断接触这个世界的生活、人物、物品与异常结构，同时无意中把地球的物质、知识和概念带入其中。

深层故事：世界自身存在概念体、权柄以及不同概念之间的关系和斗争。

最终主线：概念与权柄的斗争。

但这条根本主线不应在前期直接解释，而应从普通生活、异常物品、人物关系和事件后果中逐渐露出。

## 三、世界底层设定：概念

核心观念：不知道，就不存在。

这里的“不存在”不仅指物质不存在，也指某种结构尚未被世界真正认知、组织和实现。

因此：
- 外形相似 ≠ 结构相同；
- 功能相似 ≠ 原理相同；
- 地球上的物品可以在这个世界出现类似物，但底层结构完全不同；
- 当新的概念进入世界后，世界会开始尝试理解、组合、实现它；
- 概念体拥有意识，并能够主动参与某些结构的形成；
- 人、物、概念体、组织之间可以共同推动新结构产生。

这个世界的技术/物品不是简单科技树，而更像：材料 × 生物 × 概念 × 认知 × 时间 → 新结构。

所以王度经常会产生一种感觉：“看起来很像地球的东西，认真研究以后却完全不是地球的东西。”

## 四、王度的角色定位

王度不是传统意义上的救世主或天选之子。

他的核心身份：外来者、观察者、参与者、变量。

他与读者拥有接近的认知位置。王度对很多事情也不知道。他不会因为自己来自地球，就自动知道这个世界的真实机制。

他的行为经常只是出于好奇、日常需求、地球人的生活习惯、想尝试某个东西、想解决眼前的问题。但世界会接住他的行为，并产生远超他预期的后续。

## 五、主要故事线总表

当前已建立的核心故事线：
1. 门先生 / 门 / 光爆 / 概念体晋升线
2. 阿英与门先生、阿英父亲的关系线
3. 西瓜 → 度瓜线
4. 啤酒 / 微生物 / 发酵线
5. 金属罐 / 铁艺师傅线
6. 身份凭证线
7. 身份凭证 → 软件 / 网络 / 概念体关注线
8. 王度与异种族 / 兽耳族等日常接触线
9. 概念体与权柄主线
10. 门先生最终结束自我、归还“门”的权柄线
11. 门先生留下回地球物品线
12. 王度与阿英最终回到地球线

这些线不是互相独立的章节，而是可以在不同时间节点交叉。

## 六、门先生线

### 1. 门先生过去
门先生过去曾属于某个重要势力，位置较高。后来退出。

阿英的父亲年轻时被门先生收养/带在身边，两人存在“亦师亦父”的关系。后来阿英父亲与门先生一起退出原组织。

因此门先生线同时牵涉旧势力、阿英父亲、阿英、门、概念体、权柄。具体组织名称、历史和关系暂时保留。

### 2. 天空光球
第一章中门先生制造的大范围“光爆/光球”：本质上是一扇关闭的门。

普通人看到的是天空中的巨大光球。不同层级的人拥有不同解释：
- 普通人：巨大光球 / 灾害 / 攻击；
- 一般势力：门先生造成的大规模异常事件；
- 部分概念体：知道这与“门”有关；
- 更高层存在：知道门先生正在晋升为概念体。

具体机制暂不完全解释。

### 3. 光爆之后的认知错位
普通人会认为：门先生让那一片的人全部死了。

因此普通人、普通势力可能对门先生产生仇恨、恐惧、复仇、调查、排斥。

但部分概念体以及真正接触核心结构的势力知道：那些人没有真正进入“死亡”。这里涉及“生命”和“死亡”两个概念。

所以不同人会拥有不同认知：
- 普通人：他们死了。
- 部分高层：他们没有死亡。
- 更深层：这件事情本身可能无法用普通意义上的“杀死/救走”解释。

因此不会出现所有势力立刻统一围剿门先生的情况。但也不会让所有人都异常理智。

应该保留：真正想复仇的人、不知道真相而报复的人、试图调查的人、认为门先生必须处理的人、知道事情复杂而选择观望的人、与“门”存在关系因此不敢轻举妄动的人。

### 4. 后续释放
后期门先生会以某种方式把当初消失的人释放出来。世界才逐渐发现：当年那些人并没有死亡。

### 5. 门先生最终结局
大后期：门先生以某种方式结束自我。不是简单的“被杀死”，而是结束自己作为“门”的承载者/拥有者的状态。

然后：把“门”的概念与权柄归还整个世界。

核心意义：概念和权柄不应永远属于某一个人。门先生曾经拥有、使用、依赖“门”，最终却主动放弃对它的占有。

## 七、西瓜 → 度瓜线

王度将地球西瓜带入世界。阿英吃西瓜。

拜师、喝酒、吃西瓜相关章节最后：阿英拿走啤酒罐、西瓜皮以及西瓜种子。

阿英没有把西瓜全部吃掉，而是留下种子。之后找到认识的人/朋友，让对方尝剩下的西瓜。对方觉得好吃。阿英告诉他：把这些种子做成能种的东西，以后就能一直吃。

于是这条线脱离王度继续运行。种植者尝试、失败、改进、成功、繁殖、传播。

最终市场上出现了这种瓜，当地人给它命名为“度瓜”。

### 王度后来再次看到度瓜
某一天王度独自去市场，突然看到一种水果。他愣住。

它和地球西瓜高度相似。他询问店主：“这是什么？”店主告诉他：“度瓜。”王度听到名字时，可能会对发音产生误解，甚至不确定是不是自己理解的那个“度”。

他进一步观察：外形像西瓜；敲击声音像西瓜；切开以后是红瓤；但是种子已经变成更细小的黑籽。

王度震惊，然后毫不犹豫：啪。直接把瓜打开。

周围路人开始指指点点。店主非常不爽，觉得这个客人行为异常、让自己丢脸。王度却完全沉浸在震惊里，马上吃了一口。

这个场景重点不是解释度瓜，而是让王度通过一个普通市场事件意识到：自己当初带来的东西已经在世界里运行了很久。

### 后续人物关系线
后来王度再次遇到当初种植度瓜的人。对方已经认识王度，态度发生变化：热情、感谢、主动送瓜、让王度免费吃、讲述自己如何把种子重新种出来。

## 八、啤酒线

王度从地球进入这个世界时，把地球微生物带了进来。

这里不是“这个世界原本有地球意义上的细菌和酵母”，而是王度自己不知道自己携带了这些东西。

这些微生物进入世界后，逐渐形成影响。

世界原本拥有自己的分解、腐朽、保存等机制。因此不能简单设定成“没有细菌 → 树叶永远不腐烂”。正确方向是：这个世界原本存在自己的生物/概念结构来完成腐朽、分解等过程，但地球微生物进入后，增加了一套新的结构。

影响可以慢慢表现为：肉类保存时间变化、食物出现不同的变质方式、发酵现象出现、某些原本不存在的味道产生、市场价格变化、人们开始注意食品保存问题。

最终王度制作啤酒。

重点：王度不是因为知道“这个世界没有细菌”，所以主动把细菌概念带过去。而是王度不知道自己带来了什么 → 做啤酒 → 行为产生结果 → 世界第一次真正接触到新的生物/发酵结构。

因此：概念不是提前存在的设定，而是在行为发生后进入世界。

## 九、金属罐 / 铁皮线

拜师、喝酒、吃西瓜之后，王度与阿英在市场/商店活动。

王度注意到一个非常小的细节：当地容器主要是玻璃、陶瓷等材料，没有地球意义上常见的铁皮罐/金属易拉罐结构。

这个信息不需要解释，只需要王度看见。

之后某一天：世界突然出现了铁皮罐 / 罐头 / 易拉罐之类的新东西。

来源可以是王度留下的啤酒罐，或者有人观察、研究、尝试复制之后产生的新结构。

### 铁艺师傅线
未来王度可能遇到一个做铁艺/金属加工的人。对方突然认识王度，表现得非常热情：让徒弟/家人拿茶、热情招待、主动交流。

王度一开始不明白。后来才知道：对方的行业受到了他留下的东西影响。

这个故事线用来体现：一个王度根本没有主动经营的人际关系，却因为某个物品的传播自然形成了。

## 十、身份凭证线

当地不叫“手机”。真正的名称是“身份凭证”。

它不是单纯硬件。其核心原始形态是一种类似史莱姆的小型生物。

这种生物原本是概念体尝试创造/改造某种智慧生命的产物。

它具有强可塑性、概念适应、信息承载、身份识别、一定程度的智能、与使用者建立特殊连接的能力。

最终没有成为最初设想中的智慧物种，反而发展成了身份凭证 + 信息网络 + 公共服务的基础。

## 十一、王度获得身份凭证

阿英带王度去一个当地店铺。阿英不会说“我带你去买手机”，因为当地没有“手机”这个概念，她可能只是说“带你去弄个东西”。

店里老板与一堆小型史莱姆状生物接触。老板随手抓一个出来给王度。

王度使用当地身份认证，把自己的身份凭证贴上去/接触。

这一瞬间：身份凭证与王度产生精神/概念层面的连接，并根据王度的认知发生变化。

最终：小史莱姆 → 王度认知中的“手机”形态。

因此它不是被“做成手机”，而是根据王度的概念成为王度理解中的手机。

## 十二、身份凭证的真实结构

它实际上是：生物 + 概念 + 身份系统 + 信息网络 + 软件/功能结构的结合体。

因此王度手里拿着的是一个“物品”，但本质上他正在使用的是一套被生物承载的概念系统。

它还可以拥有类似“小AI”的存在，帮助王度找人、联系人、传递信息、接收消息、管理身份、处理基础服务。

## 十三、身份凭证的网络逻辑

王度拿到身份凭证的一瞬间：他认识哪些人，这些关系信息会被身份凭证理解。

它可以根据“认识关系”进行抽象连接。

例如：王度认识阿英，阿英认识B，B认识C，那么理论上王度可以通过关系网络找到世界上非常遥远的人。

但：能找到 ≠ 对方愿意回复。

这会形成有趣的社会现象，例如有人很闲，群发“你认识阿英吗？认识阿英的回复一下”，导致一些知名人士被陌生人骚扰。

## 十四、身份凭证的交互方式

身份凭证可以语音控制、普通操作、无声交互、类似脑内确认。

脑控不是“脑子一想就自动发送”。因为它仍然是一个外在的身份凭证，而不是身体器官。即使脑内确认，也需要使用者明确完成确认。

所以误操作概率较低。

## 十五、身份凭证的公共属性

第一次获得身份凭证免费，因为身份凭证由这个世界的一些概念与组织共同维护，是一种公共服务。

后续损坏、重新获得、升级等服务可能收费。

它不是商业手机公司单独提供的东西，而是社会基础设施。

## 十六、王度试图改变身份凭证

王度拿到身份凭证以后，很自然地想：相机、相册、音乐、图片、论坛、软件、网络服务。

但他很快发现：身份凭证不是地球手机。

它目前可能只能打电话、发信息、进行身份相关服务。

王度知道“相册”是什么，但知道概念 ≠ 知道如何实现。

因此他自己尝试开发，结果做不出来。

## 十七、论坛线

王度最终提出“论坛”。

这是这个世界网络结构中的新概念。最开始它只是一个很简单的东西，但可以让人发布问题、查看别人提出的问题、讨论、搜索信息、分享想法。

因为“论坛”第一次出现，很多人会觉得它有点奇怪，但确实有用。

于是王度把自己想做的东西发布上去：想做相机、相册、让身份凭证记录图像、让它播放音乐。

但王度自己不会实现。

## 十八、概念体介入身份凭证线

身份凭证店老板最开始也不懂王度到底在说什么，因此不会直接“无限群发”。更合理的传播方式是：老板 → 同行业者 → 相关职业/组织 → 研究者 → 概念体。

例如老板发出信息：“今天有一位客人的身份凭证产生了特别变化，变成了扁平的手机形状。他提出了很多我们不知道如何实现的功能，希望有人帮助。”

这个消息在相关行业内部传播。最终某个概念体感知到了这件事情。

概念体开始主动关注王度。

然后王度的身份凭证突然响起。有人联系他，可能是电话，也可能是信息。

这才是概念体真正进入王度生活的节点之一。

## 十九、异种族 / 兽耳族日常线

世界中存在兽耳、异种族、非人类生物。

王度看到以后，不一定带有地球人的特殊偏见。他的反应可以非常直接：“我能摸一下吗？”

对方震惊，因为王度的态度非常自然、好奇，没有恶意。对方可能同意。

甚至反过来：“其实我也对人类挺好奇的。你能让我摸摸吗？”

于是王度反过来被摸。

这条线用来体现：人的主观意图会通过表情、语气、动作和态度被别人感知。

同一句“我能摸一下吗？”可以因为语气、眼神、距离、动作不同，而被理解成好奇、善意、冒犯、骚扰或敌意。

## 二十、宏观势力的表现方式

世界不采用非常明显的帝国、王国争霸、国家大战、五国大战作为主要表现形式。

势力存在，但更多表现为：组织、行会、概念体关系、地方势力、行业、研究者群体、某种共同体、旧组织、人际网络。

势力之间可以不和、争执、打架、谈判、合作、利用、观察、复仇，但不会动不动“所有人上去拼个你死我活”。

普通人的生活应尽量保持连续。

## 二十一、王度的回忆 / 地球视角

王度过去在地球的经历，不应该作为另一条大型冒险线频繁展开。

它主要用于表现王度现在为什么这么想、为什么做这个选择。

回忆服务于人物，而不是人物服务于回忆。

当王度看到某件事情，可以用很短的回忆让读者理解王度为什么会这么做。

## 二十二、故事线之间的交叉原则

故事线不是“一条线写完 → 下一条线”，而是可以在同一章节中交叉。

例如：
西瓜线 → 度瓜出现 → 王度再次遇见 → 农业变化。
啤酒线 → 发酵 → 食品变化 → 金属罐线 → 铁艺师傅线。
身份凭证线 → 网络 → 论坛 → 概念体关注 → 新软件。
门先生线 → 光爆 → 各势力反应 → 生命/死亡概念 → 后期真相。

这些线可以在某一章同时出现。

例如王度去市场买东西，这一章可能同时取景：度瓜、金属罐、某个认识王度的人、身份凭证收到的新消息、一个与门先生有关的人在远处出现。

但王度不需要知道这些线全部是什么。

## 二十三、最终回到地球

大后期：门先生已经结束自我，“门”的概念与权柄重新归还世界。

王度手中还保留着门先生留下的回地球物品。

最终：王度与阿英回到地球。

但他们不知道现在是哪一年、具体在哪里、地球过去了多久、自己原来的生活是否还存在。

他们只知道：回来了。

## 二十四、结尾的感觉

不是宏大回归，不是全世界欢呼，不是最终BOSS被击败。

更像一个人从梦境醒来，或者一个人从出租屋走出去，突然发现外面的世界已经不是自己记忆中的样子。

他们从另一个世界的过去，走进地球未知的现在。

## 二十五、结尾的两个世界

王度与阿英回到地球以后，另一个世界没有结束。

那个世界继续运行：度瓜继续生长，啤酒继续发展，身份凭证继续运行，概念体继续活动，门的概念继续存在，新的人继续认识王度留下的东西。

与此同时，地球的故事也没有结束。王度只是重新进入了它。

因此：
> 那边的故事没有结束。
> 这边的故事也没有结束。

真正结束的只是：王度在另一个世界的这一段“取景”。

## 二十六、《试验》的最终叙事原则

### 1. 世界先运行，故事后取景
不是为了章节创造世界，而是世界本身先存在，章节只是截取其中一个窗口。

### 2. 小事件产生长因果
王度做一个很小的事情，世界可能用几十章、几百章把它接住。

### 3. 人物不负责解释世界
人物只知道自己知道的东西，尤其不能让门先生承担“世界观百科全书”的功能。

### 4. 真相不等于信息
某件事情可以已经发生，但王度不知道，读者也可以不知道，其他人知道的部分也可能不同。

### 5. 宏大世界通过细节显现
市场里少了铁皮罐、一个陌生人突然认识王度、肉最近涨价、身份凭证突然收到陌生信息、某个以前不存在的水果出现在摊位，这些东西比直接说“世界发生了巨大科技革命”更有生命感。

### 6. 时间线不是章节目录
时间线负责保存事情什么时候发生、影响谁、之后产生什么。章节负责决定王度什么时候看见其中哪个节点。

### 7. 故事允许留白
尚未确定的概念体具体名称、某些组织、门的完整机制、回地球物品的具体形态、某些技术实现、光爆的全部解释，暂时保持开放。

## 二十七、当前创作工作方式

以后新增设定时，优先考虑：“这是什么故事线？”

然后记录：
1. 起点
2. 参与人物
3. 中间变化
4. 时间跨度
5. 影响对象
6. 可能产生的后续
7. 可以在哪些章节被王度“取景”
8. 哪些信息王度知道
9. 哪些信息读者知道
10. 哪些信息暂时只有作者知道

最终再把多个故事线放入时间轴，寻找自然交叉点。

> 不是先想“这一章写什么”，而是先让世界里发生一些事情，再决定王度这一章恰好看见什么。
