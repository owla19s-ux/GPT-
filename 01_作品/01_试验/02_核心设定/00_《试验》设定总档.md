# 《试验》设定总档

> 项目名“试验”为暂用名，正式书名未定。
> 本文档是《试验》的当前核心设定主档。作品内部资料优先于公共写作系统；修改核心设定时必须检查关联节点。

## 一、状态标签

- 【确定】作者当前确认，后续默认不可随意改动。
- 【当前表现】正文已经出现，但更深层解释仍可能变化。
- 【作者真相】作者暂时知道，角色/读者尚不知道。
- 【待定】已有方向，但尚未正式确定。
- 【留白】故意不回答，后续可作为悬念。
- 【废弃】旧设定，不再作为当前事实。

最高原则：世界事实、角色认知、读者认知、作者真相、未决设定必须分开。

# 二、项目总定位

王度推开一扇不该存在的门，进入一个被“门”与其他力量影响、处于动荡和末世感中的世界。

王度不是传统救世主，更接近一个“变数”：

> **他的出现不是为了直接拯救世界，而是让这个世界重新拥有拯救自己的可能。**

核心主题：
- 偶然与必然
- 特殊与常态
- 代价与选择
- 催化而非拯救

总体结构：
1. 生存与认知
2. 真相与颠覆
3. 影响与改变
4. 深入敌境

# 三、王度

## 基本信息
- 27岁，男，蓝星/地球人。
- 主角、特例、“在天上飞的鱼”。
- 穿越前无势力归属。

## 人格核心
王度不是天生冷漠。冷静、内敛、疏离来自长期失去与失败后的生存方式。

> **观察 → 判断 → 行动。**

他习惯观察而不是参与，因为参与意味着投入，而投入意味着再次失去。他务实，不纠缠无法改变的事情，只关注下一步。

## 27年人生
- 0–9岁：南星内陆小镇，家庭完整。
- 9岁：洪灾与泥石流摧毁小镇，父母、爷爷奶奶死亡；大爸幸存但为救人瘫痪，之后精神恶化。
- 9–14岁：孤儿院、沉默、疯狂读书，形成观察代替参与的方式。
- 14–16岁：大爸死亡，处理后事，留下洪灾前模糊全家福。
- 16–20岁：打工、自考、学手艺、社交、恋爱、游戏，努力把生活填满。
- 20–22岁：看见规则不公平、起点差异、人情与关系，但选择假装看不见。
- 22–25岁：尝试赚钱、社交、感情，逐渐无法接受自己变成不愿成为的人。
- 25–27岁：承认很多事情改变不了，固定生活习惯，表面正常，内里空洞。

深处一直有某种东西等待：不是具体目标，而是重新产生“想要”的感觉。

## 穿越前
炎热夏天，王度提着半个西瓜和几瓶啤酒回家。钥匙插入锁孔，向右拧两圈。门开了，门内不是自己的客厅。

## 第一章后的心理变化
“我要”不是简单的“我要力量”，更深层是重新获得相信事情可以存在另一种可能的能力。

> **力量不保证结果，但力量让改变结果成为可能。**

> **有了力量，就有了一点可能性。**

第二章开始后：冷还在，但开始有好奇；警惕还在，但开始愿意接近；沉默还在，但开始主动说话。对阿英更暖一些，但不突然亲近。

# 四、阿英

- 女性，年龄留白，约170cm。
- 引导者、保护者。
- 干练、少言、执行力强；压力下冷静；不擅长表达情感。
- 所属：门先生派系。
- 对王度：引导对象、同伴。
- 敌对对象：追猎者“狗”。

能力：
- 概念能力：门。
- 当前属于“人使用概念”。
- 能打开空间通道并传送。
- 自身觉醒能力存在但尚未揭晓。
- 淡金色概念纹路从眉心向两侧蔓延至指尖。

装备：黑色雨衣、深灰作战服、薄甲、胸甲、战术包、短剑、匕首。

第一章状态：奉门先生之命带王度离开，在连续开门过程中明显消耗并受伤。

第二章关系变化：王度亲眼确认她为自己付出代价，因此通过注意伤势、缩短距离、自然沉默、关心行动能力等方式变暖，而非直接表白式表达。

# 五、门先生

老年男性，代号/职位名“门先生”，正式姓名未知。

特点：旧衣、多补丁，脊背始终挺直；沉稳、温和，但在重大决定上极其决绝。

拥有两种力量：
- 自身觉醒能力：火。
- 概念能力：门。

火：暗金色纹路从身体浮现，引燃安静而强大的炽白色火焰。

门：与“门”概念体深度合作。普通状态下由人使用门；关键时刻可进入：

> **“门用他”——概念体主导，人作为载体。**

## 第一章结尾状态
旧设定“自爆/死亡/牺牲”已经废弃。

> **门先生没有死亡。**

他在把王度和阿英送走后释放巨大力量并进入另一种状态。巨大光团属于他的能力/状态变化，不是死亡证明，也不是已经确定的自爆。

光爆目前只作为尺度参考，可理解为多倍核爆级别的视觉规模；完整机制、持续时间、力量上限、不可逆代价均待定。

王度和阿英可以误判或无法判断他的状态。

# 七、力量体系

## 自身觉醒能力
从个人内部产生的力量。可以天生拥有或在危机、刺激、仪式等条件下觉醒。通常消耗体力、精力、生命力等。

已知：门先生——火。

## 概念能力
人类与具有自我意识的概念体合作，从概念体获得力量。不同概念体拥有不同性格、意志、偏好、选择标准、规则和代价。

关系可以是契约、交易、友谊、寄生等。

### 人使用概念
人类主导，概念体提供力量。阿英属于此类。

### 概念使用人
概念体主导，人类作为载体，力量可能远超正常范围，但人类可能被消耗。门先生曾进入此状态。

是否存在中间层级，待定。

---

# 八、概念体

概念体是：

> **具有自我意识的抽象概念存在。**

它不是普通力量源，也不是神魔，而是某个概念拥有自我意识后的存在。可能包括门、火、时间、重量、记忆等。

概念体独立于人类存在，在人类甚至生命出现之前就可能存在。

人类通常不能直接看到概念体，只能通过能量纹路、空间异常、能力表现、直觉、特殊共鸣等间接感知。

等级参考：
- E–B：人使用概念
- A：人使用概念的高阶极限
- S：概念体自身存在层级
- SS：多个概念体协同造成的异常现象
- SSS：理论极限/极少出现

**等级不等于战斗力。**

---

# 九、“门”概念体

- S级古老概念体。
- 有自我意识。
- 核心权柄：开门。
- 核心欲望：打开更多的门。

概念范围包括：洞穴入口、房门、城门、国门、空间通道、状态转换、心门、生门、死门、命运之门、机会之门等。

门不是创造这些东西；它本身就是“门”这一概念产生了意识。

觉醒理论：概念扩张到最终连“门这个概念自身的门”都被打开，于是产生自我意识。具体时间和方式仍可调整。

## 三税
### 欲望税
产生“想开门”的欲望本身就与门发生关系，欲望成为门概念体的食粮。

### 灵子税
使用概念能力消耗灵魂周围的灵子储备；灵子耗尽可能造成灵魂碎裂。

### 能量税
体力与精力消耗，是使用者最容易感知到的表层代价。

不同等级、不同人与概念体关系下税率不同；概念体理论上可以采取不同税率甚至主动免除部分税。

---

# 十、灵子

灵子是概念能力的重要燃料，存在于世界底层。

- 环境存在游离灵子。
- 个体拥有灵子储备。
- 不同个体灵子吸附资质不同。
- 资质影响出生储备、恢复速度和上限。
- 可以自然恢复，但通常较慢。
- 高强度能力使用会短时间消耗大量灵子。
- 耗尽可能造成灵魂碎裂。

大多数角色并不知道灵子的真实存在，只知道“使用能力之后很累”。真正机制属于作者层面的深层设定。

灵子吸附资质不是绝对固定，特殊事件、训练、灵魂冲击等可能改变。

# 十一、能力等级

门能力参考：
- E：缝隙
- D：裂口
- C：门径
- B：空间门
- A：传送门
- S：概念体自身
- SS：概念协同
- SSS：理论极限异常

等级衡量规模、稳定性、精度、概念参与程度，不能直接当作战斗力排名。

门先生跨世界召唤旧设定曾标为SS，但目前只保留为参考：可能涉及跨世界、可能性、其他概念体介入以及“概念使用人”状态；具体参与者和程度全部开放。

# 十二、“可能性”

“可能性”是重要深层概念，但尚未完全定稿。

当前确定方向：王度的到来与可能性存在某种关系；他的重要性不只是力量，而是他的存在改变某些原本几乎确定的结果。

未确定：
- 是否本身就是概念体；
- 是否参与王度穿越；
- 是否主动选择王度；
- 是否与门合作；
- 有多少其他概念体参与；
- 王度究竟是被门选中，还是自己打开了门。

---

# 十三、“究竟是谁打开了谁”

目前允许三种解释同时存在：

A：门拉来了王度。门主动选择王度，门先生是媒介。

B：王度打开了门。王度真正打开的第一扇门可能不是空间门，而是自己长期压抑的“想要”。

C：双方互相打开。门打开通往王度的门；王度也打开通往这个世界的门。

> **门找到了王度。**
> **王度也找到了门。**
> **只是他们都不知道，是谁先伸手的。**

该问题暂时不回答，可作为长期悬念。

# 十四、世界状态

整体：动荡、末世感明显。

可见迹象：灰烬荒野、逃亡、废弃山谷、军事化装备、不同势力冲突、概念能力使用者被追踪。

初始山谷：王度穿越抵达地，三面树木与崖壁，一面矮丘和远方山影，地面有湿漉漉草木灰，东侧远方存在重大事件/战场。

传送密室：地下、深灰色石砖墙、暗金纹路、约五米直径圆形平台，纹路像精密仪器电路，是门先生派系据点之一。

逃亡途中：草地、碎石坡、黄土地、干裂硬地。

# 十五、势力

## 门先生派系
正式名称未定。已知成员包括门先生、阿英、中年男人；掌握一定门能力，拥有科技侧和玄幻侧装备资源，处于被追猎状态，内部存在矛盾，可能有安全区。

名称、组织结构、理念、规模、内部派系及对外关系待展开。

## 追猎者“狗”
不是怪物，而是不同势力的人。追逐门术/空间能力使用者，能够追踪空间能力留下的痕迹，有组织性和战术能力，会判断威胁程度。门先生巨大光爆出现后撤退。

真实目的、组织结构、技术/能力来源待揭示。

# 十六、装备体系

科技侧：外观高科技，但本世界可能没有相应制造能力。来源可能包括其他世界借来的投影、概念体具现、其他概念支撑。可能不是稳定实体，损坏后可能消散。

玄幻侧：短剑、匕首、长枪等，来源可能为本世界特殊制造、概念具现或其他世界借入。部分武器可能有概念附着或特殊材质。

深层疑点：是否存在“科技”概念体、“借”的真正代价、投影与实体的界限、概念附着武器如何形成。

# 十七、第一章《开门》

功能：
- 压缩王度27年人生；
- 完成现实世界→异世界转场；
- 建立王度、阿英、门先生关系；
- 展示门与火；
- 引出追猎者；
- 展示王度异常共鸣；
- 让“我要”发生；
- 让王度进入新的世界。

表面：门把王度带到另一个世界。

深层：
> **王度人生中第一扇真正打开的门，是他自己的门。**

结尾：王度与阿英逃离，东方出现巨大光团；作者事实为门先生没有死亡；阿英受伤疲惫，两人开始真正成为同行者；最后阿英第一次问王度姓名。

# 十八、第二章定位

核心动作：
> **问 → 看 → 了解 → 试验**

这是王度的行动脉络，不是教学式四段结构。

第一章：冷冽、警惕、压抑、突然被力量击穿。
第二章：冷仍在，但开始松动；出现好奇；对阿英出现温度；开始主动接触世界。

第二章不要：
- 大段世界观讲解；
- 让阿英成为设定百科；
- 继续堆第一章级别的爆炸追杀；
- 突然把王度写成热血型主角；
- 让风格突然轻浮。

真正意义：
> **第一章：世界打开王度。**
>
> **第二章：王度开始打开世界。**

# 十九、叙事与文风

总基调：冷冽、克制、意象化、有重量感，不以热血爽感为核心，以氛围、细节和人物内在张力推动剧情。

正文以王度第一人称为主；楔子等特殊章节可使用其他视角。第一人称中避免用“他”指代王度。

展示而非告知：优先动作、表情、感官、距离、停顿、环境、行为选择。

比喻：陌生化，符合王度观察者思维；一段只保留少量最有力比喻，避免俗套。

对话：简短、有留白、不把设定解释塞进对话。阿英简短务实；门先生沉稳温和；王度克制、观察、问题精准。

战斗即人物：王度观察→判断→行动，能跑不战；阿英利落、少废话、目的明确。紧张时短句、短段、少修饰、感官优先；沉淀时可以舒展并增加环境与感官细节。

# 二十、信息层级

这是本项目长期执行的核心机制：

1. **世界事实**：作者确定真正发生的事情。
2. **角色认知**：角色当前知道什么。
3. **读者认知**：正文当前让读者知道什么。
4. **作者真相**：作者知道但暂时不告诉读者的东西。
5. **未决设定**：作者自己也尚未决定的东西。

例如：
- 世界事实：门先生没有死。
- 角色认知：王度只知道门先生释放巨大光团，不知道去了哪里。
- 读者认知：可以认为他消失了，但不能得到死亡结论。
- 作者真相：门先生真正进入了什么状态尚未公开。
- 未决：可能性是否是独立概念体。

# 二十一、设定依赖关系

《试验》的设定不是树状结构，而更接近网络。修改一个核心设定时，要追踪影响节点。

例如“门先生没有死亡”会影响：门先生状态 → 第一章结尾 → 王度判断 → 阿英态度 → 门先生派系未来状态 → 后续回忆/真相 → “门用他” → 光团能力 → 读者第一章认知。

修改门能力会影响：阿英能力、门先生能力、穿越机制、三税、灵子、等级体系、追猎者追踪机制、装备来源、世界历史、王度未来能力。

修改可能性会影响：王度被选中、跨世界召唤、门先生召唤、门概念体、其他概念体、王度“我要”、故事主题、最终真相。

所以不能只修改一个角色卡里的句子。

# 二十三、当前废弃设定

## 门先生死亡
【废弃】旧版本：门先生在第一章末尾自爆/死亡，光爆后无存留。

# 二十四、未来设定维护规则

新增或修改设定时优先记录：

```text
【修改对象】
【旧设定】
【新设定】
【状态】确定 / 当前表现 / 作者真相 / 待定 / 留白 / 废弃
【影响范围】角色 / 剧情 / 系统 / 世界 / 主题
【是否需要回写正文】是 / 否 / 暂不
【是否影响读者当前认知】是 / 否
```

不要直接“改一句话”。先判断它属于哪个设定节点，再追踪关联节点。
