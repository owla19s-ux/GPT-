# 烟雨江南作品研究：综合写作规则 v0.1

## 定位

这不是模仿某一部作品的句子，而是把《尘缘》和《狩魔手记》中观察到的叙事机制抽象成可执行规则。

## 一、世界

### R1 世界必须能产生压力
世界规则不能只是百科资料。资源、制度、地理、力量体系、社会结构必须能够限制人物。

### R2 先建立正常，再制造异常
读者需要知道“正常状态”，异常才有冲击力。

### R3 大世界必须落到小事件
宏大世界最终必须通过一个人、一件物品、一次选择表现出来。

## 二、人物

### R4 性格优先用选择表达
少写“他很冷静”，多写他在危险中如何判断。

### R5 性格是长期重复选择的结果
人物的稳定性来自多个场景中重复出现的决策倾向。

### R6 人物内部允许矛盾
理性与情感、本能与规则、利益与责任可以同时存在。

## 三、剧情

### R7 每个重要事件必须改变至少一个状态
可以改变：
- 人物关系
- 信息
- 资源
- 权力
- 身体
- 世界局势
- 人物认知

### R8 冲突必须产生反馈
行动之后必须留下后果，否则冲突只是视觉效果。

### R9 信息分层揭示
不要一次解释所有答案。

现象
→ 线索
→ 推断
→ 新问题
→ 真相的一部分
→ 更大的问题。

## 四、场景

### R10 景物服务剧情
景物至少承担一种功能：
- 氛围
- 预兆
- 信息
- 象征
- 阻碍
- 对照。

### R11 使用尺度变化
宏观
→ 区域
→ 场景
→ 人物
→ 动作
→ 微观细节。

### R12 具体物质细节增强真实感
食物、水、武器、建筑、天气、身体状态等具体事物可以成为世界可信度的支点。

## 五、对话

### R13 每段重要对话至少承担两项功能
例如：
信息 + 关系
威胁 + 性格
幽默 + 世界观
情感 + 剧情。

### R14 对话体现力量关系
身份不同的人说同一句话，压力应该不同。

## 六、战斗与高强度冲突

### R15 战斗前先明确条件
双方目的、环境、能力、限制、风险至少有一部分明确。

### R16 动作必须有反馈
攻击
→ 命中/失败
→ 身体或环境变化
→ 新判断
→ 下一动作。

### R17 战斗结果必须改变后续
不能打完就恢复原状。

## 七、情绪

### R18 情绪以累积为主
重要情绪应该有前置行为、记忆、关系与压力。

### R19 少量克制可以提高爆发力
不是所有情绪都立即说出来。

### R20 用动作承载情绪
沉默、停顿、回头、握紧、避开目光、改变行动，都可以比直接解释更有效。

## 八、长期写作系统

以后加入新的作者样本时，不直接复制风格，而是记录：

作者/作品
→ 观察
→ 机制
→ 可执行规则
→ 与已有规则冲突处
→ 最终进入个人写作规则。

最终目标不是“写得像烟雨江南”，而是形成属于本项目的独立写作系统。
