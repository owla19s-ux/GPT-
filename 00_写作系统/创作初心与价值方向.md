# 创作初心与价值方向

## 一、核心愿望

写作最终不是为了制造更多刺激，而是为了真实世界。

核心愿望很简单：

> **希望大家不要活得那么苦，自己也是。**

因此，作品可以娱乐、可以爽、可以悲伤、可以愤怒，但最终应该尊重真实的人，以及真实的人所处的世界。

## 二、理解人的方式

一个人的问题很少只有一个原因。

人的今天可能来自漫长的累积：

**个人 → 家庭 → 教育 → 工作 → 社会 → 制度 → 历史 → 文明**

这些层次彼此影响，又不断反馈。

因此面对一个人的痛苦、错误和矛盾，不应轻易用“这个人就是坏”解释全部。

尤其需要理解：

- 孩子的学业压力、成长压力和未来焦虑；
- 父母自身承受的生活与工作压力；
- 家庭成员之间压力的传递；
- 普通劳动者面对竞争、工作与生存的压力；
- 不同职业群体各自面对的约束；
- 个体缺少时间、资源、知识和心理空间时，调整自己的困难。

**理解处境不等于取消责任。**

作品既要看到一个人做错了什么，也要看到他为什么会走到那里。

## 三、对现实的观察

现代社会中，很多人似乎都处于持续消耗状态。

孩子可能很累，父母可能很累，老师、公务员、警察、普通劳动者也可能很累。

当一个社会中越来越多的人都需要寻找短暂的情绪出口时，值得追问的不是“为什么他们这么脆弱”，而是：

> **为什么生活需要这么多出口？**

文学、游戏、影视、短视频以及其他娱乐都可能成为情绪出口。

即时释放并不天然有问题。

真正值得关注的是：

**压力 → 出口 → 短暂释放 → 回到原来的压力**

如果故事能够进一步提供理解、共鸣、尊严、希望、行动感或新的视角，那么它就可能不只是短暂麻醉，而成为一种更有价值的情绪体验。

## 四、写作的意义

希望写出的故事能够让不同的人获得不同的东西：

### 疲惫的人

可以进入一个安静的小世界。

**种田、经营、生活、陪伴。**

不是因为他没有野心，而是因为现实已经足够喧闹。

### 愤怒的人

可以把无法说出口的情绪暂时放出来。

不是单纯煽动，而是让他感觉：

> “原来有人理解我为什么愤怒。”

### 无力的人

可以重新获得一点主体性。

不是一定要成为天下第一，而是发现：

> **“原来我还有选择。”**

### 失落的人

可以看到人与人的关系、尊严和重新开始的可能。

### 好奇的人

可以通过故事理解更大的世界。

## 五、对“爽”的态度

不反对爽点。

但希望区别：

### 消费型爽感

**刺激 → 释放 → 消退 → 寻找更强刺激**

### 有因果的快感

**积累 → 压力 → 选择 → 突破 → 结果 → 改变 → 新问题**

真正希望追求的是后者。

可以让读者爽，但不能只让读者爽。

## 六、现实映射

读者会主动把虚构世界翻译成自己的现实。

修仙中的“杂役、外门、内门、真传”可以被理解为现实中的职业层级、身份与晋升。

“天骄被宗门逼走”可以对应现实中人才、组织与机会之间的矛盾。

“下山种田”可以成为对现代竞争生活的退出幻想。

“迎刃而解”则代表一种非常特殊的快感：

> **原来我并不是完全没有办法。**

因此写作可以创造虚构世界，同时允许读者在其中看见自己的现实。

## 七、创作伦理

不把复杂现实简单归结为几个反派。

不把普通人塑造成没有思想的工具。

不把父母、教师、劳动者、管理者等群体简单标签化。

不因为解释结构就取消个人责任。

也不因为强调个人责任，就假装结构不存在。

努力同时写：

**人 + 关系 + 组织 + 制度 + 时代。**

## 八、最希望写出的世界

理想中的作品不一定告诉读者：

> “你必须成为英雄。”

它也可以告诉读者：

> **“你可以先活下来。”**

> **“你可以休息。”**

> **“你可以离开不适合自己的地方。”**

> **“你可以重新建立自己的生活。”**

> **“你不是唯一一个感到痛苦的人。”**

> **“即使世界很复杂，人仍然可以做出自己的选择。”**

最终，希望故事不是替现实寻找一个简单答案，而是让读者在离开故事的时候，比进入故事之前多一点理解、多一点力量，或者至少——多一点喘息。

## 九、创作方向关键词

**真实世界 / 人的处境 / 主体性 / 共鸣 / 情绪出口 / 种田 / 发泄 / 尊严 / 关系 / 结构 / 选择 / 因果 / 希望 / 建设**
