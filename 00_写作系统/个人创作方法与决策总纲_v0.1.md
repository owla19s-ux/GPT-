# 个人创作方法与决策总纲 v0.1

> 本文用于统一当前已经讨论确认的创作方式、偏向与决策原则。
> 核心目标：让创作适配作者真实的思维方式、精力状态与现实条件，而不是要求作者适应传统写作流程。

---

# 一、作者的核心思维特征

## 1. 高想象力、强抽象思维

作者擅长在脑中构建：

- 世界
- 空间
- 人物
- 关系
- 事件
- 能力
- 权柄
- 意识体
- 历史
- 多世界/多时间线
- 抽象结构及其相互关系

而且这些元素可能不是线性出现，而是以一个整体模型同时存在。

## 2. 主要创作方式：先“看见”，后表达

作者写作时通常不是先想到文字，而是：

**脑内形成画面/结构 → 人物和世界在其中运动 → 观察画面与情绪 → 尝试转换成文字。**

因此语言更像是输出接口，而不是主要思考载体。

## 3. 核心困难不是缺少内容

真正的问题是：

**内部模型的信息量 > 语言能够准确表达的信息量。**

有些空间关系、情绪、抽象结构和同时发生的状态，很难用普通文字完整描述。

因此不能把“表达困难”简单理解为“不会构思”或“不会写”。

---

# 二、明确否定的创作方式

## 1. 不采用高强度逐句校对作为主要工作流

传统流程：

**构思 → 写作 → 自己逐句检查 → 修改 → 再检查**

对作者消耗极大。

尤其当文字与脑内画面存在偏差时，作者需要重新把非语言的内部模型翻译成语言来纠正 AI。

这会造成极高的认知负担。

原则：

> **不能让作者长期充当 AI 的文字质检员。**

## 2. 不要求固定日更

不采用：

- 每天必须写多少字；
- 固定章节产量；
- 为了更新而更新。

当前现实条件包括精力、身体、心理和经济限制，因此创作系统必须允许低频甚至长时间停顿。

## 3. 不先做庞大世界观工程再强迫进入正文

作者过去容易一次性构建：

世界、历史、角色、能力、权柄、意识体、地球线、穿越线、多时间线等。

这种方式很容易出现：

**设定极其丰富 → 正文开始 → 第二章左右耗尽精力 → 项目长期搁置。**

因此未来允许构建世界，但不能要求世界观“完成”以后才能开始故事。

---

# 三、推荐创作工作流

## 第一阶段：灵感捕获

作者想到什么就直接发送。

可以是：

- 一句话；
- 一个画面；
- 一个角色；
- 一种感觉；
- 一个关系；
- 一个世界设定；
- 一个反转；
- 一条规则；
- 一张草图；
- 一段语音；
- 无法完整解释的抽象结构。

不要求完整。

核心原则：

> **先保存，不强迫表达完整。**

---

# 四、AI的主要职责

AI不是单纯“代写”。

AI承担的是：

## 1. 外部记忆

记录作者想到的所有素材，避免想法因为没有立即写下来而丢失。

## 2. 结构化

将碎片整理成：

- 世界设定
- 人物
- 关系
- 时间线
- 事件
- 伏笔
- 情绪节点
- 主线
- 支线
- 已使用内容
- 待使用内容

## 3. 节点安排

一个想法不等于马上进入正文。

AI应判断其适合出现的时间、章节和情境。

例如一个重要身份信息可以提前数十章埋下痕迹，再在合适节点揭示。

## 4. 连续性维护

AI后台负责检查：

- 人物人格
- 人物当前状态
- 已知/未知信息
- 空间关系
- 时间线
- 世界规则
- 能力限制
- 事件因果
- 伏笔
- 前后设定冲突

尽量不把这些检查工作转嫁给作者。

---

# 五、正文生成方式

## 核心模式

> **作者负责“看见”，AI负责“翻译”。**

作者可以直接说：

> “我脑子里看到的是……”

不需要先把它写成漂亮的小说语言。

AI负责：

**思维/画面 → 结构理解 → 场景 → 小说正文**

而不是：

**思维 → 作者先硬翻译成文字 → AI润色 → 作者再次校对**

## 一次生成不是终稿

第一次生成的主要目的，是尽可能还原作者脑内模型。

作者只需要判断：

> **“是不是我脑子里的那个东西？”**

如果不对，不要求作者修改句子。

可以只反馈：

- “不对。”
- “情绪不对。”
- “画面不对。”
- “空间关系不对。”
- “感觉不对。”
- “这里应该更冷。”
- “这里不是上下级关系。”
- “这里我脑子里是同时存在的。”

AI根据这种低成本反馈重新翻译。

---

# 六、允许非语言输入

由于作者存在明显的“内部结构高于语言表达”的特点，未来创作接口应该支持：

**文字 + 语音 + 图片/草图 + 碎片描述**

尤其是复杂结构，可以直接画图。

作者不必解释到数学般准确。

AI先识别结构，再向作者确认关键差异。

---

# 七、创作指令体系

可以逐渐形成极简操作：

### 「收录」

只保存想法，不展开正文。

### 「整理」

把近期碎片整理进世界、人物、事件等结构。

### 「安排」

判断某个想法应该在哪个剧情节点出现。

### 「开写」

把当前准备好的场景直接转化为正文。

### 「回看」

让 AI 汇报目前故事状态，而不是要求作者自己翻大量文件。

---

# 八、故事构建原则

## 1. 先人，再世界

世界观可以巨大，但读者一次只能跟随少量人物。

因此：

**人物 → 场景 → 行动 → 信息 → 世界扩张**

优先于：

**世界百科全书 → 设定解释 → 人物进入故事。**

## 2. 世界逐渐显形

不要一次性解释所有规则。

让读者先看到异常，再逐步理解原因。

可以采用：

**现象 → 判断 → 行动 → 新信息 → 修正判断 → 更大的世界**

## 3. 巨大设定必须通过人物进入读者

复杂的世界、制度、能力和历史，最终应该通过：

- 人的命运
- 人的选择
- 人际关系
- 冲突
- 日常生活

让读者感受到。

而不是依赖大段设定说明。

---

# 九、当前明确的内容偏向

## 1. 种田/生活型

核心不是简单农村生活，而可能是现代人面对巨大时代压力后的：

**退出竞争 → 建立小型可控世界 → 获得安全感、生活感和人与人的连接。**

核心情绪：

**喘息、安定、掌控、生活、陪伴。**

## 2. 发泄/共鸣型

不是单纯制造愤怒，而是：

**压抑 → 看见自己的处境 → 获得表达 → 主体性恢复 → 情绪释放。**

可以产生：

**愤怒、共鸣、尊严、眼泪、释放。**

## 3. 主体性恢复型

重要快感不是：

> “我天下无敌。”

而是：

> **“原来我不是完全没有办法。”**

力量可以来自：

- 规则
- 信息
- 证据
- 合作
- 技能
- 组织
- 专业能力
- 离开
- 重新开始

## 4. 尊严/翻身型

例如：

**杂役 → 外门 → 内门 → 真传**

能够映射现代人的身份、职业层级和晋升焦虑。

核心不是修仙数字，而是：

> **“我什么时候才能不再被当成随时可以替换的人？”**

## 5. 离开型

例如“天骄离开宗门”。

核心情绪：

> **“如果这里不珍惜我，我可以去别的地方。”**

不是简单报复，而是重新获得选择权。

---

# 十、对爽文的决策

不反对爽点。

但不希望作品依赖：

**刺激 → 释放 → 消退 → 更强刺激**

更偏向：

**积累 → 压力 → 选择 → 突破 → 结果 → 人物/世界改变 → 新问题**

原则：

> **可以让读者爽，但不能只让读者爽。**

快感最好留下：

- 人物变化
- 关系变化
- 世界变化
- 新信息
- 新问题
- 情绪余韵
- 对现实的新理解

---

# 十一、对现实的态度

写作始终为了真实世界。

不是简单寻找：

> “谁是坏人？”

而是观察：

**个人 + 家庭 + 组织 + 制度 + 社会 + 历史 + 文明**

一个人的问题可能有无数个原因。

但结构性解释也不能取消个人责任。

核心原则：

> **理解处境 ≠ 免除责任。**

> **看到个人，也看到个人背后的世界。**

---

# 十二、文学与现实的关系

作品可以成为现实压力的缓冲带。

有人需要：

**种田 → 逃离洪流。**

有人需要：

**发泄 → 把压抑释放出来。**

有人需要：

**共鸣 → 发现自己不是一个人。**

有人需要：

**流泪 → 让长期压抑的情绪获得出口。**

有人需要：

**迎刃而解 → 发现自己原来还有办法。**

因此文学不只是提供答案，也可以提供：

**喘息、理解、尊严、选择和希望。**

---

# 十三、作者最终偏向

当前创作价值方向可以浓缩为：

> **不希望大家过得苦，自己也是。**

因此希望写出的作品：

- 尊重普通人的处境；
- 不把复杂社会简化成几个反派；
- 不把人物写成剧情工具；
- 允许人物犯错；
- 允许人物反抗；
- 允许人物退出；
- 允许人物建设自己的生活；
- 允许读者爽；
- 允许读者哭；
- 允许读者发泄；
- 最终让读者比进入故事时多一点理解、多一点力量，或者至少多一点喘息。

---

# 十四、目前的总决策

### 作者负责

**世界、人物、画面、抽象结构、情绪、方向、最终判断。**

### AI负责

**记忆、整理、结构化、节点安排、连续性、文字转换、后台检查、正文执行。**

### 系统负责

**让作者能够持续创作，而不是把创作变成另一种消耗。**

最终工作流：

**灵感出现**
→ **直接输入**
→ **AI收录**
→ **结构化**
→ **自动安排节点**
→ **作者某天“脑内画面成熟”**
→ **AI把画面转换成正文**
→ **AI自行检查**
→ **作者只做低负担确认**
→ **继续积累**

核心目标不是：

> **“让作者每天写得更多。”**

而是：

> **“让作者脑中的世界终于有机会真正活下来。”**
